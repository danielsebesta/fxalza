# fxalza

Open source nástroj, který na Discordu ukáže náhled odkazů z Alzy: název, cenu, slevy, kupóny, cashback a klubové ceny.

Stačí v odkazu přepsat `alza.cz` na `fxalza.cz`:

```
alza.cz/<produkt>-d12345.htm  →  fxalza.cz/<produkt>-d12345.htm
```

Kdo odkaz otevře v prohlížeči, skončí rovnou na Alze.

## Poděkování

- [FxEmbed](https://github.com/FxEmbed/FxEmbed) (MIT) - inspirace a rozpoznávání botů
- [Alza-Benefit-Prices](https://github.com/DeRus0/Alza-Benefit-Prices) - inspirace pro celý projekt a jeho logiku, hlavně klubové ceny a kupóny
